# Shopping conversation memory and Supabase user data

Quick-Own does not expose a separate Memory button or memory editor. Channel3 owns conversational continuity through its Conversational Agent thread ID. Supabase stores the user's History records, wishlist, and successfully placed orders.

See [Channel3 conversation memory and Supabase user data](channel3-conversation-memory.md) and run [the Supabase migration](supabase_channel3_memory.sql) before testing signed-in accounts.
